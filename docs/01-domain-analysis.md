# Анализ предметной области: Маркетплейс товаров в Таджикистане (marketplace)

## 1. Организация и проблемы
Маркетплейс — это веб-платформа для автоматизации купли-продажи товаров в Таджикистане, объединяющая независимых продавцов под единым брендом. Покупатели получают возможность сравнивать цены, читать отзывы и оформлять заказы в единой корзине с безопасной сделкой. Сейчас савдои онлайн в стране ведётся через Instagram, Telegram-каналы и доску объявлений Somon.tj, что создаёт риски мошенничества, отсутствие единой корзины и непрозрачную логистику. Продавцы учёт остатков ведут в блокнотах или Excel, из-за чего часто продают уже отсутствующие товары.

### Проблемы текущего процесса
1. Отсутствие единой корзины и безопасной сделки: покупатели делают переводы напрямую продавцам в Instagram, что создаёт высокие риски мошенничества.
2. Сложная логистика: доставка за пределы Душанбе неорганизована, нет единого трек-номера и отслеживания статуса заказа.
3. Дублирование данных: продавцы ведут учёт в Excel, что приводит к ошибкам и продаже отсутствующих товаров.

## 2. Актёры
| Роль в системе | Код | Кто это | Что делает в системе |
|---|---|---|---|
| Покупатель | `buyer` | Физическое лицо, приобретающее товары | Ищет товары, добавляет в корзину, оформляет заказ, оставляет отзывы |
| Продавец | `seller` | ИП или компания, торгующая на платформе | Создаёт карточки товаров, управляет остатками, подтверждает заказы |
| Курьер | `courier` | Сотрудник службы доставки | Видит назначенные заказы, меняет статус на "доставлен" |
| Модератор | `moderator` | Сотрудник поддержки маркетплейса | Проверяет новые товары, одобряет или отклоняет карточки |
| Администратор | `admin` | Владелец платформы | Управляет пользователями, категориями, тарифами и разрешает споры |

## 3. Бизнес-процессы
| Процесс | Участники | Результат |
|---|---|---|
| Регистрация и верификация продавца | `seller`, `admin` | Аккаунт продавца со статусом `verified` |
| Добавление товара в каталог | `seller`, `moderator` | Карточка товара со статусом `active` |
| Оформление и выполнение заказа | `buyer`, `seller`, `courier` | Доставленный товар, закрытый заказ, начисление рейтинга |
| Возврат товара | `buyer`, `seller`, `admin` | Возврат средств, статус заказа `returned` |

### 3.1. Оформление и выполнение заказа (подробно)
1. **Триггер:** Покупатель (`buyer`) переходит в корзину и нажимает "Оформить заказ", указывая адрес и способ доставки.
2. Система создаёт заказ со статусом `pending` и уведомляет продавца (`seller`).
3. Продавец проверяет наличие товара. Если есть — меняет статус на `confirmed`. Если нет — отменяет заказ (`cancelled_by_seller`).
4. Система назначает курьера (`courier`). Статус заказа меняется на `in_delivery`.
5. Курьер доставляет товар покупателю. Покупатель осматривает и оплачивает (наложенный платёж).
6. Курьер меняет статус на `delivered`. Система начисляет продавцу рейтинг.

**Исключения:**
- Покупатель не отвечает курьеру 24 часа: статус `delivery_failed`, товар возвращается продавцу.
- Покупатель отказывается от товара: курьер оформляет возврат, статус `returned`.

## 4. Объекты данных
| Объект | Основные сведения |
|---|---|
| Пользователь | ID, имя, телефон, e-mail, пароль (хеш), роль (`buyer`, `seller`, `admin`) |
| Продавец | ID, название магазина, ИНН, рейтинг (1-5), статус верификации, адрес склада |
| Товар | ID, название, описание, цена, остаток, ID категории, ID продавца, статус (`active`, `moderation`) |
| Заказ | ID, ID покупателя, сумма, адрес, способ оплаты, статус (`pending`, `confirmed`, `delivered`), дата |
| Отзыв | ID, ID заказа, ID товара, оценка (1-5), текст, дата |

## 5. Глоссарий
| Термин | Определение |
|---|---|
| Маркетплейс | Торговая площадка, объединяющая независимых продавцов под единым брендом |
| Селлер | Продавец, зарегистрированный на платформе и прошедший верификацию |
| Корзина | Временное хранилище выбранных товаров перед оформлением заказа |
| Escrow | Система безопасной сделки: деньги передаются продавцу после получения товара |
| Модерация | Проверка контента (товаров) на соответствие правилам площадки |
| Трек-номер | Уникальный идентификатор отправления для отслеживания доставки |
| FBS | Модель работы: продавец хранит товар у себя и передаёт курьеру |
| Рейтинг | Среднее арифметическое оценок покупателей, отражающее надёжность продавца |
