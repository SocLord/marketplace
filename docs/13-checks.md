# Отчёт по лабораторной работе 13: PDO, Репозитории, CRUD

## Таблица проверок требований

| № | Требование из методички | Реализация в проекте "Бозори Онлайн" | Статус |
|---|---|---|---|
| 1 | **Подключение PDO**: `config.example.php` в Git, `config.php` в `.gitignore`, 3 настройки (ERRMODE, FETCH, EMULATE). | Реализовано в `src/Core/Database.php` с драйвером `sqlsrv`. Файл `config.php` добавлен в `.gitignore`. | ✅ |
| 2 | **Репозитории**: минимум 3 класса в `src/Repositories/`, весь SQL только там. | Созданы `ProductRepository`, `CategoryRepository`, `ShopRepository`. | ✅ |
| 3 | **CRUD и PRG**: список, создание, удаление (строго POST). После POST — редирект (302) на GET. | Реализовано в `ProductController`. Метод `store()` делает `header('Location: /products?msg=created')`. | ✅ |
| 4 | **Поиск и фильтры**: текстовый поиск (`LIKE` с `addcslashes`) + 2 фильтра из списков. | Реализовано в `buildWhere()`. Фильтры: `q` (поиск по имени) и `category_id`. | ✅ |
| 5 | **Пагинация**: `OFFSET...FETCH` через `bindValue(..., PDO::PARAM_INT)`. В базе ≥ 25 записей. | Реализовано в `paginate()`. В базе `MarketplaceDB` более 25 товаров (4 страницы). | ✅ |
| 6 | **JOIN и Отчёт**: список показывает названия из ≥ 2 справочников. 1 отчёт с `GROUP BY`. | Запрос `SELECT` содержит `JOIN categories` и `JOIN shops`. Отчёт в `CategoryRepository::withProductCounts()`. | ✅ |
| 7 | **Серверная валидация**: возврат 422 при ошибке, форма с данными и текстом ошибок. | Реализовано в `Validator.php` и `ProductController::store()`. | ✅ |
| 8 | **Обработка ошибки FK**: при удалении связанной записи — понятное сообщение, а не 500. | В `ProductController::delete()` перехватывается `PDOException` с кодом 547 (SQL Server). | ✅ |

## Как проверить (инструкции для преподавателя)
1. **Пагинация и JOIN**: Откройте `http://localhost:8000/products`. Видно 10 товаров, названия категорий и магазинов подтянуты через JOIN. Внизу 4 страницы.
2. **Поиск**: Введите "asus" в поле поиска. Таблица отфильтруется без перезагрузки страницы (через GET-параметры).
3. **Валидация**: Перейдите по ссылке "Илова кардани мол". Нажмите "Захира кардан" с пустыми полями. Появятся красные ошибки, код ответа HTTP 422.
4. **Защита от XSS**: Все данные, выводимые в шаблонах, обернуты в `htmlspecialchars()`.
5. **Отчёт**: Откройте `http://localhost:8000/reports/categories` — видна агрегация товаров по категориям с использованием `GROUP BY`.
