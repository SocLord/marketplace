# Маркетплейс товаров в Таджикистане (marketplace)

**Тема из силлабуса:** Информационная система «Маркетплейс»  
**Автор:** Наврузов Шахзод  
**Группа:** 40.01.01

## Описание
Веб-платформа для автоматизации купли-продажи товаров в Таджикистане. Объединяет независимых продавцов, предоставляет покупателям единую корзину, безопасную сделку и интеграцию с местными службами доставки.
