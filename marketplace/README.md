# 🛒 Лоиҳаи Маркетплейс (Онлайн-Бозоргоҳи бисёрфурӯшандагӣ / Multi-Vendor Marketplace)

Комплекси мукаммали веби тиҷорати электронӣ бо пуштибонии якчанд фурӯшандагон, тақсими худкори фармоишҳо, утоқи шахсии фурӯшанда бо омори фурӯш аз рӯи моҳҳо ва низоми модератор барои санҷиши молҳо пеш аз нашр.

---

## 🏛️ Меъморӣ ва технологияҳо (Стек технологий)

- **Пойгоҳи додаҳо (База данных)**: Microsoft SQL Server (SSMS), пойгоҳи `MarketplaceDB` (порт `14330`, корбар `Shahzod`).
- **Бэкенд (Backend)**: Go (Golang) 1.24+ / GORM / Gorilla Mux / JWT v5 / BCrypt / Multipart Uploads.
- **Фронтенд (Frontend)**: Vue 3 / Vite 8 / Vue Router 4 / Lucide Icons / Дизайни замонавӣ дар услуби маркетплейсҳо бо палитраи махсуси изумрудӣ (Deep Teal & Amber) бе такрори рангҳои WB ё Ozon.
- **Файли SQL барои SSMS**: `database/schema.sql` ва `database/seed_data.sql`.

## 📋 Иҷрои ҳамаи талаботҳои супориш

1. **Феҳристи молҳо бо категорияҳо, аксҳо ва нарх**:
   - Каталоги пурра бо аксҳои баландсифат, нархи аслӣ, нархи пешина ва тахфифи фоизӣ (`-15%`, `-25%`).
2. **Ҷустуҷӯ ва филтр**:
   - Филтри фаврӣ аз рӯи нарх (аз — то бо сомонӣ).
   - Филтр аз рӯи категорияҳо ва мағозаҳои мушаххас.
   - Сортировка: аз рӯи маъруфият, рейтинг, нарх (арзон ба гарон, гарон ба арзон) ва навтаринҳо.
3. **Сабад ва фармоиш (Корзина и заказ)**:
   - Гурӯҳбандии аёнии молҳо дар сабад аз рӯи фурӯшандагон (Бастаи 1: TechStore, Бастаи 2: ModnoStyle).
   - Оформленияи фармоиш бо нишон додани суроға, телефон ва тарзи пардохт.
4. **Саҳифаи алоҳидаи мағозаи фурӯшанда**:
   - Саҳифаи шахсии ҳар як мағоза (`/shop/techstore`, `/shop/modnostyle`) бо баннер, логотип, тавсиф, рейтинг, телефон, суроға ва ҳамаи молҳои тасдиқшудаи ин мағоза.
5. **Фикру мулоҳизаҳо ва баҳо ба мол**:
   - Харидорон метавонанд баҳо (1 то 5 ситора) ва шарҳи худро нависанд.
   - Ҳисобкунии худкори рейтинги миёнаи мол дар база.
6. **Модератсияи молҳо пеш аз нашр**:
   - Ҳар як моли нави фурӯшанда бо статуси `pending` сабт мешавад ва дар каталог нишон дода намешавад то он даме, ки модератор онро санҷида тасдиқ накунад (`approved`).
   - Ҳангоми радкунӣ (`rejected`) модератор сабаби радкуниро менависад.
7. **Талаботи махсус: Тақсими фармоиши якчанд фурӯшанда ба қисмҳо**:
   - Агар харидор молҳоро аз якчанд фурӯшанда фармоиш диҳад, фармоиш ба ҷадвали `orders` ва ба қисмҳои `sub_orders` тақсим мешавад.
   - Ҳар як фурӯшанда ТАНҲО ҚИСМИ ХУДРО мебинад ва иҷро мекунад (`shop_id = current_shop_id`). Фурӯшандагон молҳо ва маблағи якдигарро дида наметавонанд!
8. **Талаботи махсус: Утоқи шахсии фурӯшанда бо омори фурӯш аз рӯи моҳҳо**:
   - Диаграммаи сутунӣ ва ҷадвали муфассали даромад аз рӯи ҳар як моҳ (Январ, Феврал, Март... Сентябр, Октябр, Ноябр).
   - Нишондодҳои даромади умумӣ, даромади моҳи ҷорӣ, шумораи бастаҳо ва молҳои серфурӯштарин.

## 🗄️ Сохтори пойгоҳи додаҳо дар Microsoft SQL Server (SSMS)

Ҷадвалҳои сохташуда дар пойгоҳи `MarketplaceDB`:
1. `users` — корбарон бо нақшҳо (`buyer`, `seller`, `moderator`, `admin`).
2. `shops` — мағозаҳои фурӯшандагон бо тавсиф ва рейтинг.
3. `categories` — бахшҳои молҳо.
4. `products` — молҳо бо нарх, бақия ва статуси модераторӣ (`pending`, `approved`, `rejected`).
5. `orders` — фармоиши умумии харидор.
6. `sub_orders` — қисмҳои ҷудогонаи фармоиш барои ҳар як фурӯшанда.
7. `order_items` — номгӯи молҳо дар ҳар як қисми фармоиш.
8. `reviews` — фикру мулоҳизаҳо ва баҳодиҳӣ.

### Иҷрои скрипти SQL дар SSMS:
Барои аз нав сохтан ё дидани скрипт дар SQL Server Management Studio:
Файли `marketplace/database/schema.sql`-ро дар SSMS кушоед ва тугмаи **Execute (F5)**-ро пахш намоед.

## 🚀 Тарзи оғоз бахшидан (Запуск проекта)

### 1. Бэкенд (Go)
```powershell

npm run dev
```
